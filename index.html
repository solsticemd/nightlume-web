The idea

Designed to disappear into the game.

Nightlume doesn't try to turn Minecraft into another operating system. The interface is built around the information you actually need while keeping everything else quiet.

Principles

Less interface. More game.

Every part of Nightlume follows the same principle: if something doesn't improve the experience, it doesn't need to be there.

✦

Visual first

Nightlume is designed around hierarchy, spacing and readable information instead of effects for the sake of effects.

◌

Lightweight by design

No unnecessary layers, giant menus or visual clutter. The client should stay responsive while the game remains the focus.

◇

Consistent

One visual language across HUD, panels, ClickGUI and settings.

↝

Smooth

Animations are short, subtle and purposeful.

+

Modular

Enable only the modules and information that actually matter to you.
